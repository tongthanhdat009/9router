## Classification semantics

- `ALREADY_CORRECT`: documented automatic/pass-through behavior and current request/accounting path preserves it.
- `NOT_APPLICABLE_WITH_EVIDENCE`: registry entry exposes only an out-of-scope non-LLM modality.
- `SUPPORTED_BY_PROVIDER_BUT_NOT_INTEGRATED`: provider capability requires missing lifecycle/API/executor support.
- `BLOCKED_WITH_EVIDENCE`: official docs remained insufficient/inaccessible, or current code requires a review-gated fix before final classification.
- `IMPLEMENTED`: reserved for changes completed and passed by `review-gate`; none claimed before implementation gate.
